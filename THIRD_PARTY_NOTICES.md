# Third-party components

The application packages include these Java libraries. Their license texts and
notices remain in their JARs where provided. The MIT-derived texts shipped with
the Bouncy Castle and SLF4J libraries are also in `licenses/`.

| Component | Version | License |
| --- | --- | --- |
| [Apache MINA SSHD Core](https://mina.apache.org/sshd-project/) | 2.20.0 | Apache-2.0 |
| [Apache MINA SSHD Common](https://mina.apache.org/sshd-project/) | 2.20.0 | Apache-2.0 |
| [Bouncy Castle Provider](https://www.bouncycastle.org/) | 1.81 | MIT-style Bouncy Castle license (`licenses/Bouncy-Castle-MIT.txt`) |
| [Gson](https://github.com/google/gson) | 2.11.0 | Apache-2.0 |
| [SLF4J API](https://www.slf4j.org/) | 2.0.17 | MIT (`licenses/SLF4J-MIT.txt`) |
| [SLF4J NOP](https://www.slf4j.org/) | 2.0.17 | MIT (`licenses/SLF4J-MIT.txt`) |
| [JCL over SLF4J](https://www.slf4j.org/legacy.html) | 1.7.36 | Apache-2.0 |
| [Error Prone Annotations](https://github.com/google/error-prone) | 2.27.0 | Apache-2.0 |

Native packages also bundle a Java runtime. Its legal notices are included in
the runtime image generated from the JDK used to build the package.
